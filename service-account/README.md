# Service Account
# This repository demonstrates how to configure Service Account in Google Cloud using the Console.
#Scenario
In yor Google Cloud Console, go to IAm -> Service Account
Click on create service account
Select any service account title of your choice(eg, Al-hassan-account)
click create and continue
Next, you choose a role to the service account(e.g developer role)
You can crate more than one roles to a service account by clicking on add another role
Next you select the users(email address) that'll be allowed to use this service account, and if you like you can live it blank meaning every user on your organization can use it.
click on done, and your service account will successfully be created
![Grant Access Screenshot](/screenshot/Screenshot(158).png)
Next you need to create a key for the service account, it's like a password that will allow you to use the service account
just click on the service account mail to create a key
go to the third option that says key, and click on add key, Note: you can create multiple keys which is equivalent to multiple passwords
After clicking on add key, click create new key and select json, it'll download a Json file in your browser
Congratulations, you've successfully created a key
